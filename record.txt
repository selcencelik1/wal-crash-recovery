How to read a result
---------------------
After a run, stats_output.txt contains exactly six lines:

    === STATISTICS ===
    Disk I/O: <R> reads, <W> writes
    Buffer Pool: <req> requests, <H> hits, <M> misses (<P>% hit rate)
    Evictions: <E> (<D> dirty writebacks)
    Index: <strategy>, <nodes> nodes visited
    Records: <scanned> scanned, <returned> returned

  * "I/O count" reported in the tables  = R + W   (line 2)
  * "Hit rate"                          = P%      (line 3)

Clean-state helper (run before EACH measured run so the database starts
empty; log.csv is intentionally left alone — it is append-only and
persistent per the spec, and logging performs no page I/O):

    rm -f ./*.bin output.txt stats_output.txt

A config is supplied by writing config.json. Only the lines that change
between runs are highlighted in each experiment.

================================================================================
Experiment 1 — LRU vs. MRU
================================================================================
Setup : fixed buffer pool size = 8
        index_strategy = bplus_tree.

Report: I/O count (R+W) and hit rate (P%) for each of the 4 runs.

Workloads (generate once, reuse for both policies):

    python3 workload_generator.py --mode sequential --records 100 --queries 20 --seed 42 > seq.txt ; echo stats >> seq.txt

    python3 workload_generator.py --mode random --records 100 --queries 20 --seed 42 > rnd.txt ; echo stats >> rnd.txt

config.json for LRU:

    {
      "page_size": 4096,
      "max_records_per_page": 10,
      "buffer_pool_size": 8,
      "replacement_policy": "LRU",
      "index_strategy": "bplus_tree"
    }

config.json for MRU:

    {
      "page_size": 4096,
      "max_records_per_page": 10,
      "buffer_pool_size": 8,
      "replacement_policy": "MRU",
      "index_strategy": "bplus_tree"
    }

The four measured runs:

    # 1a sequential + LRU
    rm -f ./*.bin output.txt stats_output.txt
    printf '{"page_size":4096,"max_records_per_page":10,"buffer_pool_size":8,"replacement_policy":"LRU","index_strategy":"bplus_tree"}' > config.json
    python3 archive.py config.json seq.txt ; cat stats_output.txt

    # 1b sequential + MRU
    rm -f ./*.bin output.txt stats_output.txt
    printf '{"page_size":4096,"max_records_per_page":10,"buffer_pool_size":8,"replacement_policy":"MRU","index_strategy":"bplus_tree"}' > config.json
    python3 archive.py config.json seq.txt ; cat stats_output.txt

    # 1c random + LRU
    rm -f ./*.bin output.txt stats_output.txt
    printf '{"page_size":4096,"max_records_per_page":10,"buffer_pool_size":8,"replacement_policy":"LRU","index_strategy":"bplus_tree"}' > config.json
    python3 archive.py config.json rnd.txt ; cat stats_output.txt

    # 1d random + MRU
    rm -f ./*.bin output.txt stats_output.txt
    printf '{"page_size":4096,"max_records_per_page":10,"buffer_pool_size":8,"replacement_policy":"MRU","index_strategy":"bplus_tree"}' > config.json
    python3 archive.py config.json rnd.txt ; cat stats_output.txt

    Workload    | LRU I/Os | LRU Hit Rate | MRU I/Os | MRU Hit Rate
    Sequential  |  59712   |    15.9%     |   58205   |    17.6%
    Random      |  15786   |    20.2%     |   13332   |    32.1%

Experiment 2 — Index Strategy Comparison
================================================================================
Setup : fixed buffer pool size = 16
        replacement_policy = LRU.

Report: I/O count (R+W) per strategy. hash_index range falls back to
        heap_scan (the Strategy field in EXPLAIN/output reflects this).

Workloads:

    python3 workload_generator.py --mode random --records 300 --queries 150 --seed 42 > eq.txt ; echo stats >> eq.txt

    python3 workload_generator.py --mode range  --records 300 --queries 150 --seed 42 > rg.txt ; echo stats >> rg.txt

config.json for heap_scan:

    {
      "page_size": 4096,
      "max_records_per_page": 10,
      "buffer_pool_size": 16,
      "replacement_policy": "LRU",
      "index_strategy": "heap_scan"
    }

config.json for hash_index:

    {
      "page_size": 4096,
      "max_records_per_page": 10,
      "buffer_pool_size": 16,
      "replacement_policy": "LRU",
      "index_strategy": "hash_index"
    }

config.json for bplus_tree:

    {
      "page_size": 4096,
      "max_records_per_page": 10,
      "buffer_pool_size": 16,
